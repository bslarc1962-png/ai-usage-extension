## Name

AI Usage Tracker：Claude 與 Codex 限額

## Short Description

在彈出視窗、圖示徽章與頁面浮層中追蹤 Claude 與 ChatGPT (Codex) 的工作階段和每週用量限額。注重隱私，免設定。

## Full Description

AI Usage Tracker：Claude 與 Codex 限額是一款瀏覽器擴充功能，適合想要更清楚、更可預測 AI 助理體驗的使用者。你可以追蹤訊息限額、查看即時倒數計時，並直接在服務頁面上顯示不干擾的用量儀表，讓你專注於工作，而不會突然撞上限額。

無論你使用 Claude 和 ChatGPT 進行程式開發、寫作、研究或深入解決問題，AI Usage Tracker 都能減少撞上限額封鎖時的摩擦，並讓你直接掌控容量的監控方式。你可以選擇浮層出現的位置，也可以選擇如何追蹤自己的限額。

主要功能：

- 即時追蹤 Claude (claude.ai) 和 ChatGPT/Codex (chatgpt.com) 的限額
- 工具列圖示徽章一眼顯示目前最高的用量百分比
- 頁面內情境浮層，直接顯示在聊天輸入框旁邊
- 使用 Shadow DOM 的可收合膠囊小工具，避免與宿主頁面樣式衝突
- 以工作階段 (5 小時) 和每週 (7 天) 為單位的容量監控
- 即時倒數計時，精準顯示限額何時重置
- 隨選重新整理按鈕，以及每 5 分鐘自動於背景同步
- 100% 私密：直接從你自己已驗證的瀏覽器工作階段讀取

使用者選擇 AI Usage Tracker 的原因：
- 快速、自動化的用量輪詢，無需手動重新整理頁面
- 更清爽的介面，可無縫融入 AI 聊天畫面
- 更能安排高強度程式開發、學習或寫作工作階段的節奏
- 安全設計，無外部伺服器、無追蹤、無遙測
- 簡單的側邊面板控制，可快速啟用或停用

適合：
- 高頻使用 Claude Code 或 ChatGPT 限額的開發者與進階使用者
- 想清楚掌握配額的 Plus、Pro 與 Team 方案訂閱者
- 想避免深度工作流程被打斷的專業人士與學生
- 厭倦了毫無預警就看到「you've reached your limit」的任何人
